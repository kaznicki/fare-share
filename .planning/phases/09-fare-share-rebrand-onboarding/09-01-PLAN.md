| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | `public/*.svg` (static SVGs served as files) | accept | SVGs are referenced via `<img src="...">` in 09-04, not inlined into HTML. Inline-SVG component (Plan 09-02) writes paths verbatim from a trusted source — no user input crosses this boundary. |
| T-09-02 | Information disclosure | `next/font/google` loader | accept | `next/font/google` self-hosts fonts at build time (no runtime fetch from Google CDN). No new exposure beyond the existing Geist loader pattern already in `app/layout.tsx`. |
| T-09-03 | Tampering | Raster generation tooling (sharp/ImageMagick/Inkscape) | mitigate | Generator runs locally on a trusted dev machine against a vetted SVG source (the just-color-fixed `app-icon-512.svg`). Verify produced PNG sizes match expected dimensions before commit (180x180, 32x32, 16x16). |

No HIGH severity threats. ASVS L1 satisfied — this plan introduces no new auth, no new input handlers, no new server endpoints, no new database writes. Threat surface is static-asset shipping.
