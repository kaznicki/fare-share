Create `components/session/ClaimableItem.tsx` — a single claimable item row.

```typescript
'use client'
import type { Item } from '@/types'

interface Props {
  item: Item
  claimants: string[]        // claims[item.id] from session state — may be empty []
  participantName: string    // current user's name — to determine 'mine' vs 'theirs'
  onClaim: (itemId: string) => void
  onUnclaim: (itemId: string) => void
}
```

**Visual states (use Tailwind classes):**
- `unclaimed` (claimants.length === 0): plain white row, gray text
- `mine` (claimants.includes(participantName) && claimants.length === 1): green tinted background (`bg-green-50 border-green-200`), bold name
- `shared` (claimants.includes(participantName) && claimants.length > 1): blue tinted (`bg-blue-50 border-blue-200`), shows split
- `theirs` (claimants.length > 0 && !claimants.includes(participantName)): gray tinted (`bg-gray-50`), shows claimants, no tap-to-claim highlight (but still tappable to add yourself)

**Row structure:**
```
[item name]                    [$9.00 ÷ 2 = $4.50]
[Alice, Bob]  ← claimant names (hidden if empty)
```

Split price display: when claimants.length > 0, show full price ÷ count = share. Format: `$X.XX ÷ N = $Y.YY`. All math in integer cents: `splitCents = Math.round(item.priceCents / claimants.length)`. Display with `(cents / 100).toFixed(2)`. When unclaimed, show only `$X.XX`.

**Tap handler:**
- If `claimants.includes(participantName)` → call `onUnclaim(item.id)`
- Otherwise → call `onClaim(item.id)`

**Claimant names display:** Show comma-separated claimant names below the item name in small gray text. Hidden if claimants is empty. This satisfies CLAIM-04 (names visible to all).

**Animation for remote claims (Claude's discretion per CONTEXT.md):** Use a brief CSS transition on background color — add `transition-colors duration-300` to the row class. No JS animation needed; the state change from WebSocket snapshot will trigger the Tailwind transition naturally.

**Accessibility:** Wrap the entire row in a `<button>` element with `type="button"` so it is keyboard and screen-reader accessible on mobile.
