From lib/ocr.ts lines 37-51 (current OCR_PROMPT — may be kept as-is per D-03):
```typescript
const OCR_PROMPT = `Extract all food and drink line items from this restaurant receipt as JSON.
Return ONLY valid JSON with this exact shape, no explanation or markdown:
{
  "items": [{ "name": string, "price": number, "qty": number }],
  "subtotal": number,
  "tax": number,
  "tip": number
}
Rules:
- items array: food and drink items only
- Exclude subtotal, tax, tip, service charge, and discount lines from items array
- price is in dollars (e.g., 12.99 for $12.99)
- qty defaults to 1 if not shown on receipt
- If a line cannot be identified as a food or drink item, omit it
- Return 0 for tax or tip if not present on receipt`
```

OCR_PROMPT is a const string. Targeted patches mean editing specific rule lines inside the template literal. DO NOT touch:
- `ReceiptItemSchema` / `ReceiptSchema` (Zod — D-02)
- `Math.round(item.price * 100)` dollar→cent conversion (D-02)
- `extractReceiptItems` function signature (D-02)
- `getOpenAI()` lazy init (D-02)
- `temperature: 0`, `detail: 'high'`, `response_format: 'json_object'` (already optimal)

<pitfall_patches>
<!-- Reference patches from research. Apply ONLY if the corresponding failure is actually observed. -->

**Pitfall 1 — Service charge / auto gratuity leaks into items** (look for an item in `items[]` whose name contains "gratuity", "service", "charge"):
Replace the line:
```
- Exclude subtotal, tax, tip, service charge, and discount lines from items array
```
with:
```
- Exclude from items: subtotal, sub-total, total, grand total, balance due, amount due, tax, sales tax, GST, HST, PST, VAT, service charge, auto gratuity, mandatory gratuity, suggested gratuity, tip, gratuity, discount, comp, coupon, and any line that is not a specific food or drink item
```

**Pitfall 2 — Grand total / subtotal leaked into items** (look for an item with price much larger than any individual food item, e.g. an "item" of $101.70 when all food items are $5-$25):
Same patch as Pitfall 1 above (the expanded exclusion list covers both).

**Pitfall 3 — Multi-quantity items not detected** (look for qty=1 with an unusually large price that equals N × a smaller nearby price, e.g. `{qty: 1, price: 14.00}` when the receipt shows `2 DRAFT BEER @ $7.00`):
Replace the line:
```
- qty defaults to 1 if not shown on receipt
```
with:
```
- qty: if the receipt shows a quantity column, "2x ITEM", "ITEM x2", or "2 @ $7.00", extract that quantity and set price to the unit price (not the extended line total); if no quantity is shown, default qty to 1
```

Apply only the patches for failures you actually observe. Do not pre-emptively apply patches for failures that have not happened (D-03: ship unchanged if the existing prompt passes all 3 receipts).
</pitfall_patches>
