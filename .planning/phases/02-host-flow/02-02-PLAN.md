    These two components are pure leaf components — no async, no side effects, just controlled editing patterns.

    **ItemRow.tsx** — `'use client'`

    Interface:
    ```
    interface Props {
      item: Item
      onChange: (patch: Partial<Item>) => void
      onDelete: () => void
    }
    ```

    Internal state: `editingField: 'name' | 'price' | null` (qty uses stepper buttons, not inline edit).

    Name cell (tap-to-edit pattern from RESEARCH.md):
    - Display: `<span onClick={() => setEditingField('name')}>{item.name || 'Tap to add name'}</span>`
    - Editing: `<input autoFocus type="text" defaultValue={item.name} onBlur={e => { onChange({ name: e.target.value }); setEditingField(null) }} />`
    - Do NOT use `contenteditable` — React reconciliation bugs. Always use `<input>`.

    Price cell (tap-to-edit, dollar display / cents storage):
    - Display: `<span onClick={() => setEditingField('price')}>${(item.priceCents / 100).toFixed(2)}</span>`
    - Editing: `<input autoFocus type="number" step="0.01" min="0" defaultValue={(item.priceCents / 100).toFixed(2)} onBlur={e => { onChange({ priceCents: Math.round((parseFloat(e.target.value) || 0) * 100) }); setEditingField(null) }} />`
    - CRITICAL: Always `Math.round(parseFloat(value) * 100)` — never parseInt or Math.floor (per STATE.md locked decision). This converts $12.99 → 1299 correctly.

    Qty stepper (not tap-to-type — steppers are faster for receipt correction per RESEARCH.md):
    - `-` button: `onChange({ qty: Math.max(1, item.qty - 1) })` (minimum qty is 1)
    - Display: `<span>{item.qty}</span>`
    - `+` button: `onChange({ qty: item.qty + 1 })`

    Delete button: `<button onClick={onDelete} aria-label="Delete item">✕</button>`

    Layout: single row, flex items-center, gap between cells, border-b. Use Tailwind v4 classes. Price input: `w-24 text-right`. Name input: `flex-1`.

  <action>
    Replace the stub from Plan 01 with the full implementation. This component is `'use client'`.

    Interface:
    ```
    interface Props {
      initial: OcrResult
      onComplete: (sessionId: string) => void
    }
    ```

    State:
    ```
    const [items, setItems] = useState<Item[]>(initial.items)
    const [taxCents, setTaxCents] = useState(initial.taxCents)
    const [tipCents, setTipCents] = useState(initial.tipCents)
    const [isPending, startTransition] = useTransition()
    const [sessionError, setSessionError] = useState<string | null>(null)
    ```

    Item mutations (immutable array updates — never mutate in place):
    ```
    const updateItem = (id: string, patch: Partial<Item>) =>
      setItems(prev => prev.map(it => it.id === id ? { ...it, ...patch } : it))

    const deleteItem = (id: string) =>
      setItems(prev => prev.filter(it => it.id !== id))

    const addItem = () =>
      setItems(prev => [...prev, {
        id: crypto.randomUUID(),  // built-in browser API, no import needed
        name: '',
        priceCents: 0,
        qty: 1
      }])
    ```

    Session creation (SESS-01, CORR-05):
    ```
    const createSession = () => startTransition(async () => {
      setSessionError(null)
      try {
        const res = await fetch('/api/sessions', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ items, taxCents, tipCents }),
        })
        if (!res.ok) throw new Error(`HTTP ${res.status}`)
        const { sessionId } = await res.json()
        onComplete(sessionId)
      } catch {
        setSessionError('Could not create session. Please try again.')
      }
    })
    ```

    IMPORTANT: `items` is sent with raw `qty` values. The server's `POST /api/sessions` handler performs qty expansion (CORR-05) — it creates N separate Item entries for each item with qty > 1. The UI does NOT expand items client-side.

    Zero-item banner (OCR-04 empty result case):
    ```
    {items.length === 0 && (
      <div className="bg-amber-50 border border-amber-200 rounded-lg p-4 mb-4 text-amber-800">
        OCR extracted 0 items — add items manually below
      </div>
    )}
    ```

    4. Scrollable item list: `items.map(item => <ItemRow key={item.id} item={item} onChange={patch => updateItem(item.id, patch)} onDelete={() => deleteItem(item.id)} />)`
