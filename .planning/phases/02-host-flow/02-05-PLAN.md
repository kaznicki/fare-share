    **In components/host/OcrReview.tsx:**

    1. Add a `newItemId` state to track the id of the most recently added item:
       ```typescript
       const [newItemId, setNewItemId] = useState<string | null>(null)
       ```

    2. Update `addItem()` to record the new item's id:
       ```typescript
       const addItem = () => {
         const id = crypto.randomUUID()
         setItems(prev => [...prev, { id, name: '', priceCents: 0, qty: 1 }])
         setNewItemId(id)
       }
       ```

    3. In the items.map render, pass `autoFocusName` and wrap `onChange` to clear `newItemId` on the first commit:
       ```typescript

         item={item}

         }}
         onDelete={() => deleteItem(item.id)}
         autoFocusName={item.id === newItemId}
       />
       ```
