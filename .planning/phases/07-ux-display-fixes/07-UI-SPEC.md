## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding (e.g. `gap-1`) |
| sm | 8px | Compact element spacing (e.g. `gap-2`, `mb-1`) |
| md | 16px | Default element spacing (e.g. `p-4`, `gap-4`) |
| lg | 24px | Section padding (e.g. `p-6`, `mb-6`) |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level bottom padding (e.g. `pb-16`) |

Exceptions:
- Touch targets: `min-h-[44px]` on all interactive rows (established pattern — SummaryScreen, ClaimableItem). Apply to "Go back to claiming" button row area as well.
- Sticky footer: `p-4` (16px) — preserve existing `TaxTipFields` padding for the total line addition.

*Source: codebase read — TaxTipFields.tsx, SummaryScreen.tsx*

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #ffffff (`bg-white`) | Page background, card surfaces, sticky footer background |
| Secondary (30%) | #f9fafb / gray-50 class | Hover states on tip presets (`hover:bg-blue-50` is fine for interactive feedback only) |
| Accent (10%) | #2563eb (`bg-blue-600` / `blue-600`) | Active tip preset button only — background + border + text |
| Destructive | not applicable | No destructive actions in this phase |

Accent reserved for:
- Active tip preset button state: `bg-blue-600 text-white border-blue-600`
- Focus rings on input fields: `focus:ring-blue-500` (established pattern — preserve, do not add to new elements)

Accent must NOT be used for:
- "Go back to claiming" button — use neutral style: `border border-gray-300 text-gray-700 hover:bg-gray-50`
- The total display line — use `text-gray-900` at semibold weight

Additional color tokens in use (established — do not change):
- `text-gray-600` — field labels ("Tax", "Tip")
- `text-gray-700` — secondary body text, section headings
- `text-gray-900` — primary body text, amounts
- `text-gray-400` — placeholder / helper text
- `text-indigo-600` — "Total owed" in personal breakdown card (SummaryScreen — preserve, do not change in this phase)
- `border-gray-300` — default input and button borders
- `border-gray-200` — card outer border
- `border-gray-100` — table row dividers

## Copywriting Contract

| Element | Copy |
|---------|------|
| Bill total label | "Total" (left side) + "$X.XX" (right side, tabular-nums) |
| Tip active state | No label change — button text stays "{N}%" regardless of active state |
| Unfinalize button | "Go back to claiming" |
| Empty state (tip presets) | No empty state — presets are always rendered; no-highlight state when tip is $0.00 or custom |
| Error state | Not applicable — no new error surfaces in this phase |
| Destructive confirmation | Not applicable — no destructive actions in this phase |

Formatting rules:
- Currency: always `$X.XX` (two decimal places, no thousands separator needed at receipt scale)
- Total label: "Total" — not "Grand Total", not "Bill Total", not "Total:" with a colon (the value column provides the pairing)

*Source: CONTEXT.md specifics section ("Total: $X.XX" — normalized to label/value split matching SummaryScreen host Total row pattern at line 82)*

## Component Inventory

Changes are surgical edits to three existing components. No new components created.

### TaxTipFields.tsx — two additions

**Addition 1: Active tip preset state (UX-01)**

Active button className:
```
flex-1 py-1 text-xs font-medium border rounded transition-colors bg-blue-600 text-white border-blue-600
```

Inactive button className (existing — preserve exactly):
```
flex-1 py-1 text-xs font-medium border border-gray-300 rounded hover:bg-blue-50 hover:border-blue-400 hover:text-blue-700 transition-colors
```

Detection expression: `tipCents === Math.round(subtotalCents * pct / 100)`
No preset highlighted when expression is false for all presets (custom or $0.00 tip).

**Addition 2: Bill total display (DISP-01)**

Placement: below the tip input `<div>`, still inside the outer sticky `<div>`, after closing the two-column flex row.

Total display className:
```
mt-3 flex justify-between items-center text-sm font-semibold text-gray-900
```

Left span: `Total`
Right span: `${(totalCents / 100).toFixed(2)}` with `tabular-nums` class

A top divider line is optional. Recommended: add `border-t border-gray-100 pt-3` to the total row wrapper to visually separate it from the tip fields — consistent with the SummaryScreen row divider pattern.

### SummaryScreen.tsx — one addition

**Addition: "Go back to claiming" button (UX-02)**

Placement: After the grand total row (line 82), still inside `{isHost && (...)}`, rendered only when `onUnfinalize` prop is provided.

Button className:
```
mt-4 w-full py-3 border border-gray-300 rounded-xl text-gray-700 font-medium hover:bg-gray-50 transition-colors
```

Button type: `type="button"` (never submit)
Minimum height: `py-3` provides 24px vertical padding; total height will exceed 44px touch target given 16px font.
