  <action>
    Create `'use client'` component `components/session/SessionRoom.tsx`.

    Props: `{ sessionId: string; participantName: string }`

    State:
    - `const [session, setSession] = useState<SessionData | null>(null)` — null until first snapshot received
    - `const [connectionError, setConnectionError] = useState<string | null>(null)`
    - `const wsRef = useRef<WebSocket | null>(null)` — store WebSocket in ref, NOT state (avoids re-renders)

    WebSocket lifecycle via `useEffect`:
    ```typescript
    useEffect(() => {
      const protocol = window.location.protocol === 'https:' ? 'wss:' : 'ws:'
      const url = `${protocol}//${window.location.host}/ws?session=${sessionId}`
      const ws = new WebSocket(url)
      wsRef.current = ws

      ws.onopen = () => {
        ws.send(JSON.stringify({ type: 'join', participantName }))
      }

      ws.onmessage = (event) => {
        const msg = JSON.parse(event.data) as ServerMessage
        if (msg.type === 'session-snapshot') {
          setSession(msg.data)
          setConnectionError(null)
        }
      }

      ws.onclose = (event) => {
        if (event.code === 1008) {
          setConnectionError('Session not found or expired.')
        }
      }

      ws.onerror = () => {
        setConnectionError('Connection lost. Please refresh to rejoin.')
      }

      return () => {
        ws.close()
      }
    }, [sessionId, participantName])
    ```

    Import `type { SessionData, ServerMessage } from '@/types'`.

    Render logic:
    1. `if (connectionError)` → render error message centered: "Session not found or expired." with a note to ask the host to reshare. Style: `text-red-500 text-center p-4`.
    2. `if (!session)` → render "Connecting..." centered in gray. Style: `text-gray-400 text-center p-8`.
    3. Main render (session loaded):
       - Heading: session items count or a simple "Session items" title
       - Participants section: `<p className="text-sm text-gray-500">Joined: {session.participants.join(', ')}</p>` — shows all current participants including self (updated on every snapshot)
       - Item list: unordered list, each item as a row showing `item.name` and `(item.priceCents / 100).toFixed(2)` formatted as price. Style each row: `flex justify-between py-2 border-b border-gray-100`. Use `item.id` as key.
       - This is a READ-ONLY scaffold — no claim interactions yet (Phase 4). Items are not tappable/interactive beyond display.

    Wrap in: `<div className="w-full max-w-sm mx-auto p-4">` inside a container.

    Key details from RESEARCH.md to get right:
    - `useRef` for WebSocket (not useState) — prevents re-renders
    - Protocol derived from `window.location.protocol` — works in HTTPS deployment
    - Cleanup `ws.close()` in useEffect return — Strict Mode safe (prevents double-mount registering two sockets)
    - `[sessionId, participantName]` dependency array — connection opens once, only when both are set
    - Check `event.code === 1008` on close for "Session not found" — server closes with 1008 for invalid session
  </action>
