From lib/ocr.ts (the mock gate — the behavior we are flipping):
```typescript
// lib/ocr.ts line 78
if (process.env.USE_OCR_MOCK === 'true') {
  console.log('[OCR] Mock mode enabled — returning fixture data')
  return OCR_MOCK_FIXTURE
}
// falls through to getOpenAI().chat.completions.create({ model: 'gpt-4o', ... })
```

Setting USE_OCR_MOCK to any string other than the literal 'true' (including 'false') causes the real GPT-4o path to execute.

From lib/ocr.ts lazy init:
```typescript
let _client: OpenAI | null = null
function getOpenAI(): OpenAI {
  if (!_client) _client = new OpenAI()  // reads OPENAI_API_KEY at first call
  return _client
}
```

The OpenAI SDK reads process.env.OPENAI_API_KEY at first call. The .env.local changes are only picked up if the dev server is restarted after editing.

From app/api/ocr/route.ts:
- Accepts multipart/form-data with `file` field
- MIME allowlist includes: image/jpeg, image/png, image/webp, image/heic
- Max size: 10MB
- Calls extractReceiptItems(buffer, mimeType) and returns the OcrResult as JSON
</interfaces>
