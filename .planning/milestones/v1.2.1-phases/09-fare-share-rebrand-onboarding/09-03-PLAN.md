| Source code -> bundled JSX | All copy, class names, and structural changes are hard-coded literals at build time. No user input crosses into rendered chrome. |

## STRIDE Threat Register

| T-09-06 | Tampering | `<img src="/logo-lockup.svg">` rendered in HeaderBar / hero blocks | accept | Static file shipped from `public/`, fixed origin, served by Next.js as an image (no script execution boundary). Plan 09-01 already verified the SVG contains no `<script>` tag. |
| T-09-07 | Information disclosure | `<Link href="/" aria-label="Fare Share home">` in HeaderBar | accept | Internal navigation only; href is a literal path. No user input flows into the link target. |
| T-09-08 | Denial of service | Repaint changes to existing components | accept | Repaint is utility-class swaps + tabular-nums additions. No new state, no new effects, no new network calls. Behavior surface is identical pre-/post-repaint. |

No HIGH severity threats. ASVS L1 satisfied — no new auth, no new input handlers, no new endpoints, no new database writes. Visual chrome only.
