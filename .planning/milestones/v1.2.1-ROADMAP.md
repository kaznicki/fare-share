## Milestone Summary

**Key Decisions:**

- Pre-process SVGs at the filesystem boundary (bake in `#C75B3D` literals) rather than using `var(--accent)` — CSS vars don't resolve through `<img>` tag boundaries
- Used `sharp` via Node script (already a transitive dep) for raster icon generation — zero new top-level dependencies
- `oklch()` for accent tokens with hex fallbacks in the Tailwind v4 bridge
- `FareShareLogo` as inline-SVG React component (not `<img>`) so CSS vars resolve at runtime for dark-mode readiness
- `HeaderBar` mounted in `app/layout.tsx` above `{children}` — applies to all routes automatically
- Wave execution (09-01 + 09-02 in parallel Wave 1; 09-03 + 09-04 in parallel Wave 2) kept file-conflict surface small

**Issues Resolved:**

- app-icon-512.svg source had only 1 `#2D6BD9` occurrence (not 2 as plan expected) — auto-fixed at copy time; brand requirement fully met
- Discovered during execution that dark mode `@media` block needed explicit removal to enforce paper background as default

**Issues Deferred:**

- PWA installability — sessions require live WebSocket; deferred per v1.0/v1.1 out-of-scope decision
- Dark mode / theme switching — explicitly out of scope this milestone

**Technical Debt Incurred:**

- None — full repaint was comprehensive; no legacy palette utilities remain per grep verification
